# threeLab · identidade visual

O símbolo é `subtract(box, box)`: um quadrado arredondado que perde o canto e vira o L de Lab. A peça removida sai deslocada, em amarelo.

## Cores

Gesso `#EFECE4` · Grafite `#141414` · Resina `#FFC21A` · Cinza `#8C8A83` · Pó `#D9D5CA`

Os tokens de interface (claro e escuro) estão em `src/viewer/style.css`. Texto sobre a Resina é sempre Grafite.

## Tipografia

Todas OFL, servidas localmente via `@fontsource`.

- **Archivo** expandida (`font-stretch: 112%`, peso 700) no wordmark e nos títulos
- **Archivo** normal no texto de interface
- **JetBrains Mono** em código, medidas e dados

## Tom de voz

Direto, técnico sem jargão, em português, com medida em vez de adjetivo: "60 mm", não "grande".
Verbos no imperativo: descreva, edite, confira, exporte.
